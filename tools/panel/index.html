面板怎么读

一、[DEC] 是什么

DEC = Decision（决策）。它是我们给代码里所有"做判断"的地方加的统一标记。 普通日志里混着 cv_bridge、BPU、launch 的噪声，加了 [DEC] 之后 就能一键过滤出"车在这一刻做了什么决定"。

格式统一为：[DEC] 区域 事件 键=值 键=值，同时会汇总成 events.csv， 一行一个事件，带相对时间，可以和录像时间轴对齐。

二、常见决策事件

事件含义对应规则
yellow stop_begin看到黄线，开始刹车停车线必须完全停住

三、比赛指标怎么算

指标规则
基本计时得分从起跑到完全停住的总秒数，越短越好
停车线未停稳+15 s / 次（最高频扣分）
闯入红色禁行区+30 s / 次
碰撞红色路锥+10 s / 次
压线+15 s / 次；持续压线按每秒 1 次算
Bonus 数字完全覆盖数字即得分，每个 −5 s

综合得分 = 时间 + 罚时 − 5 × Bonus，分数越低排名越高。 所以：一次违规 ≈ 3~6 个 Bonus 的收益，稳比快重要。

五、分段参数怎么用

一张地图切成几段，每段一套弯道相关的参数（目标速度、kp、角速度上限、 误差降速、ROI 上下边界、连续弯辅助、视觉前馈）。切换点如下：

地图段从哪开始
岔路1起步
岔路2跨过第 2 根黄线（选择支路/转弯窗口）
岔路3第 2 根黄线之后再走 段3 起始里程（转弯结束，恢复正常跟线）
环岛1起步
环岛2跨过第 2 根黄线
环岛3跨过第 3 根黄线
环岛4第 3 根黄线之后再走 段4 起始里程（环岛二出口）

用「段」下拉框选择要编辑哪一段，只改显示，不影响正在跑的车； 段号前面有 ● 的那一项就是车上现在正在用的那一段（节点每秒上报一次）。

转向偏置（steer_bias）是唯一能让车「故意偏到线的一侧」的参数， 选岔路支路就用它：单位 rad/s，负值向右、正值向左，稳态偏移 ≈ -bias / kp。用法：把段2的 steer_bias 从 -0.40 开始， 一档 0.10 往上加；同时把该段目标速度降到 0.25–0.30、kp 降到 2.0–2.5， 否则 P 项会把偏置顶回去。进分支稳了之后，用 段3 起始里程 把参数切回「不偏」的段3。

偏置是持续施加的角速度，不是瞬间脉冲：累计转角 ≈ 偏置 × (里程 / 车速)。所以「拐一下」= 一小段里程里一直打方向， 0.2 m @ 0.3 m/s @ -0.7 大约 27°。窗口短于 0.2 s 会被舵机滞后吃掉。

「拐进去再拐出来」用段2 的两段偏置：偏置1 持续里程 走完 → 两段偏置的间隔 松一下 → 转向偏置2 再打 偏置2 持续里程。偏置2 与偏置1 同号 = 再拐一次，反号 = 拐回来。 岔路段2 初值：-0.70 / 0.20 m / 0.15 m / -0.70 / 0.20 m。

段4 起始里程是唯一靠里程判定的边界，需要现场整定：第一次实车跑时， 看视频里车头压上第 3 根黄线那一帧的 d 值（参数标题或调试图上的 SEG x/4 d=…）＝黄线检测提前量，然后 阈值 = 2.27×1.08 + d + 0.15。宁可切晚，在弯里就切会切内线。

六、为什么改了参数车没变

代码里大部分参数是启动时读一次存进变量的，运行中改 YAML 不会回头重读。 所以正确流程是：改参数 → 保存 → 重启巡线节点。点「保存并重启巡线」会自动做这两步， 重启后在「生效参数」卡片和日志 [DEC] param effective 行里能看到新值。

「保存并重启巡线」的真实动作是：杀掉旧的巡线进程组并关掉旧窗口 → 弹出一个新窗口， 其他窗口不受影响。面板会一直等到新进程打出 [DEC] param effective 才提示 “重启完成”；期间会显示“正在关闭旧进程 / 等参数上报”。日志里会留下 [DEC] proc start name=follow 分界线，勾选「只看本次启动」就只显示这一次的内容。 发车信号还是开的时候不允许重启——新节点一启动就会开动。

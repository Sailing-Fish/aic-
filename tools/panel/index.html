RDK X5 双子星战术控制台 · 使用与指标说明

一、快捷键与桌面小技巧

  • `（Tab 上方反引号）：快速展开 / 收起底部 日志终端抽屉（Esc 一键收起）。
  • Shift + 点击 参数步进按钮 − / +：按 5 倍步长快速微调。
  • 顶栏 ☀ / 🌙 切换 柔光透璃 / 暗夜琉璃；👁 虚化前景卡片欣赏第 3 张原画底图（绝不占用空格键，避免误触 ⑤ 窗口发车）。

二、[DEC] 常见决策事件

事件含义对应规则
yellow stop_begin看到黄线，开始减速刹车停车线必须完全停住
yellow temp_stop停稳后继续巡线—
yellow final_stop到达终点黄线，永久停（完赛）终点
state change巡线状态切换：tracking / lost / yellow_line_detected—
red avoid_on检测到路锥/禁行区，开始绕行（side=左还是右）碰撞 +10s / 闯入 +30s
digit turn识别到数字，按数值决定转向或吃 BonusBonus −5s/个
safety deadman_on上游全静默，兜底发零速救车防失控
param effective节点启动时真正加载的参数值判断改参数是否生效

三、比赛指标怎么算

指标规则
基本计时得分从起跑到完全停住的总秒数，越短越好
停车线未停稳+15 s / 次（最高频扣分）
闯入红色禁行区+30 s / 次
碰撞红色路锥+10 s / 次
压线+15 s / 次；持续压线按每秒 1 次算
Bonus 数字完全覆盖数字即得分，每个 −5 s

综合得分 = 时间 + 罚时 − 5 × Bonus，分数越低排名越高。一次违规 ≈ 3~6 个 Bonus 的收益，稳比快重要。
